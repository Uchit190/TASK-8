# 📊 Superstore Sales Dashboard – Power BI Project

This project presents a clean, interactive Power BI dashboard built from an extended version of the Superstore Sales dataset. It visualizes key performance metrics including sales, profit, category distribution, and regional performance.

---

## 📁 Dataset Overview

**Filename:** `Superstore_Sales_Extended.csv`  
**Total Records:** 500  
**Columns Included:**

- Order ID  
- Order Date  
- Region  
- Segment  
- Category  
- Sales  
- Profit  
- Quantity  
- Discount  
- Shipping Mode

---

## 📌 Dashboard Features

### ✅ Key Visuals:
- **KPI Cards**:  
  - Total Sales  
  - Total Profit  
  - Average Discount  
  - Total Orders  
  - Profit Margin

- **Line Chart**:  
  - Monthly Sales Trend

- **Bar Chart**:  
  - Sales by Region

- **Donut Chart**:  
  - Profit by Category

- **Slicer**:  
  - Region filter to view regional performance dynamically

---

## 📈 Sample Business Insights

1. **West Region** had the highest overall sales contribution in 2023.
2. **Technology** was the top-performing category by profit margin.
3. **December** saw a sharp increase in sales, indicating seasonal demand.
4. **Corporate Segment** showed consistently higher average order values.
